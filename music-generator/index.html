How to get the best result

  • Best for most people: enter a detailed prompt and leave the other fields blank.
  • Tags: optional. Use only simple style words like country, comedy, rock, cinematic, ambient.
  • Lyrics: only use this if you already wrote your own lyrics.
  • Do not use prompt, tags, and lyrics all together.
  • Instrumental: check this for music only, with no singing.

Tip: the more specific your prompt is about genre, mood, instruments, and topic, the better the result usually feels.
